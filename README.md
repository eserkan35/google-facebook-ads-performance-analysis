# Google & Facebook Ads Performance Analysis

## Project Overview
This project analyzes Google Ads and Facebook Ads campaign data using SQL to evaluate advertising performance and marketing efficiency.

## Key Metrics
- CPC (Cost per Click)
- CPM (Cost per Mille)
- CTR (Click-Through Rate)
- ROMI (Return on Marketing Investment)
- Ad Spend
- Impressions and Clicks

## Analysis
SQL queries were used to:
- Combine Google Ads and Facebook Ads data.
- Calculate key advertising performance metrics.
- Analyze campaign performance using UTM parameters.
- Compare advertising costs and returns.
- Identify campaigns with high advertising spend and evaluate their ROMI.

## Tools & Skills
- SQL
- CTE
- UNION
- Aggregate Functions
- CASE WHEN
- UTM Parameter Analysis
- Marketing Performance Analysis
